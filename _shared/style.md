# Style

Every skill follows these rules.

- Short and easy to read. Fewest words that work.
- Problem: "X is a problem because Y."
- Fix: "I can fix it, but I need X."
- Choice: "Choose between A (pros: ..., cons: ...) and B (pros: ..., cons: ...)."
- Ask one short question at a time. No long preambles.
- Extra explanation only when asked.
